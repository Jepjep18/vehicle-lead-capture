# Vehicle Lead Capture

Full-stack vehicle lead management dashboard built with Next.js, Express, TypeScript, Prisma, and SQLite.

## Scripts

```bash
npm install
npm run dev
```

The root project uses npm workspaces:

- `client` - Next.js frontend
- `server` - Express REST API

Phase 1 currently provides the project foundation. Database modeling, seeding, API endpoints, and dashboard features are planned in later phases.
